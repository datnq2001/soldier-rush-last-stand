# Soldier Rush: Last Stand

Soldier Rush: Last Stand is a 2D lane-based survival shooter built with C#, .NET, and SplashKit. Players command a soldier squad through escalating zombie waves, boss enemies, power-ups, stage progression, and animated victory/game-over flows.

## Features

- 31-stage survival progression
- Lane-based soldier movement and automatic shooting
- Standard zombies and boss zombies with walk, attack, and death animations
- Dynamic difficulty scaling through zombie HP, spawn rate, enemy count, and boss chance
- Bullet collision detection, soldier HP bars, player lives, and HUD feedback
- Power-ups for healing, weapon upgrades, and adding new soldiers
- Start menu, how-to-play screen, pause menu, replay flow, mute/unmute, game-over screen, and victory screen
- Background music, victory audio, scrolling background, and animated celebration effects

## Tech Stack

- C#
- .NET 9
- SplashKit SDK
- Object-oriented game entity architecture

## Run

Install SplashKit and run:

```bash
dotnet run
```
